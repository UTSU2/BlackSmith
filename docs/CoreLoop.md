# CoreLoop — 핵심 게임 루프

> **[확정]** 논의로 정해진 내용 / **[미정]** 아직 정해지지 않은 내용

## 1. 메인 루프 [확정]

```
광물 구매 (상점)
   ↓
제작: 가열 → 단조 → 열처리 → 연마
   ↓
등급 결정 (제작 완성도)
   ↓
장비 판매 (상점)
   ↓
수익으로 더 좋은 재료를 구매해 더 높은 등급의 장비 제작
   ↓
(반복)
```

- **레시피 해금은 메인 루프에 포함하지 않는다.** 루프의 성장은 "판매 수익 → 더 좋은 재료 구매 → 고등급 장비 제작"으로만 구성한다.
- 더 좋은 재료가 구체적으로 무엇인지(재료 등급, 종류), 고등급 장비가 어떤 조건에서 가능한지: **[미정]**

## 2. 루프의 층위

| 층위 | 내용 | 상태 |
|---|---|---|
| 1회 제작 | 4개 미니게임을 빠른 리듬게임식으로 진행. 이 구간의 손맛이 핵심 재미 | 조작 확정, 세부 [미정] |
| 성장 | 돈 → 더 좋은 재료 → 더 비싼 장비 | 구조 확정, 수치 [미정] |
| 장기 목표 | 현재 없음 | [미정] |

## 3. 미니게임 흐름 [조작 확정]

| 단계 | 조작 |
|---|---|
| 가열 | 누름/뗌을 반복해 바를 일정 위치에 유지 |
| 단조 | 줄어드는 원이 안쪽 원과 맞을 때 클릭 (여러 위치) |
| 열처리 | 왕복하는 오브젝트가 특정 위치에 있을 때 클릭 |
| 연마 | 흠집을 클릭 후 드래그하여 제거 |

- 단계별 조작 유형이 서로 다르다(누름 유지 / 다중 타이밍 / 단일 타이밍 / 드래그).
- 속도감을 위해 현실의 제작과 달리 빠르게 진행한다.

## 4. 경제 균형 요소 [요소만 확정, 수치 미정]

- 입력(비용): 재료 구매비
- 출력(수익): 판매가 = 기본 판매가 × 등급 배율
- 시간: 1회 제작 소요 시간
- 아래는 모두 **[미정]**
  - 재료 가격, 장비 기본 판매가, 등급 배율
  - 1회 제작 목표 시간
  - 재료 품질이 등급/난이도에 영향을 주는 방식
  - 시장 가격 변동 여부

## 5. 루프 밖 후속 기능 [확정: 추가 예정]

- 장비 강화: 판매가가 등급과 강화 수치에 모두 의존
- 숙련도 시스템
- (레시피 해금: 도입 여부 [미정], 도입 시에도 메인 루프 밖)

## 6. 미정 항목

- 판정/점수/등급 산식, 등급 이름·개수
- 재료·장비 종류와 가격 수치
- 실패 시 재료 소모 여부 및 처리
- 장기 목표 구조
