# CoreLoop — 핵심 게임 루프

> **[확정]** 논의로 정해진 내용 / **[미정]** 아직 정해지지 않은 내용

## 1. 메인 루프 [확정]

```
광물 구매 (상점)
   ↓
제작: 가열 → 단조 → 열처리 → 연마
   ↓
품질 결정 (미니게임 점수 0~40)
   ↓
장비 판매 (상점)
   ↓
수익으로 더 좋은 재료를 구매해 더 높은 등급의 장비 제작
   ↓
(반복)
```

- **레시피 해금은 메인 루프에 포함하지 않는다.** 루프의 성장은 "판매 수익 → 더 좋은 재료 구매 → 고등급 장비 제작"으로만 구성한다.
- 더 좋은 재료가 구체적으로 무엇인지(재료 등급, 종류), 고등급 장비가 어떤 조건에서 가능한지: **[미정]**
- 완성품의 **등급**은 레시피에 미리 정해져 있고, **품질**(최하품~최상품)은 미니게임 점수로 정해진다. 둘은 별개다. [확정]
- 미니게임 난이도(1~10단계)의 기본값은 레시피에 정의되며, 레시피 등급보다 높은 등급의 재료를 쓰면 난이도가 조금 오르는 대신 품질 점수에 어드밴티지가 붙는다. [확정] 세부 계산은 [GameDesign.md](GameDesign.md) 참고.
- 재료를 투입하면 가장 가까운 레시피가 자동으로 선택된다. 레시피 북은 플레이어에게 보이지 않는다. [확정]

## 2. 루프의 층위

| 층위 | 내용 | 상태 |
|---|---|---|
| 1회 제작 | 4개 미니게임을 빠른 리듬게임식으로 진행. 이 구간의 손맛이 핵심 재미 | 조작 확정, 세부 [미정] |
| 성장 | 돈 → 더 좋은 재료 → 더 비싼 장비 | 구조 확정, 수치 [미정] |
| 장기 목표 | 현재 없음 | [미정] |

## 3. 미니게임 흐름 [조작 확정]

| 단계 | 조작 |
|---|---|
| 가열 | 누름/뗌을 반복해 바를 일정 위치에 유지 |
| 단조 | 줄어드는 원이 안쪽 원과 맞을 때 클릭 (여러 위치) |
| 열처리 | 왕복하는 오브젝트가 특정 위치에 있을 때 클릭 |
| 연마 | 흠집을 클릭 후 드래그하여 제거 |

- 단계별 조작 유형이 서로 다르다(누름 유지 / 다중 타이밍 / 단일 타이밍 / 드래그).
- 속도감을 위해 현실의 제작과 달리 빠르게 진행한다.
- 미니게임 난이도는 1~10단계이며 4개 미니게임에 같은 값을 쓰고, 플레이어에게 표시하지 않는다. [확정] 단계별 수치는 **[미정]**
- 각 단계는 완성도 100% = 10점으로 환산되어 합계(최대 40점)가 품질이 된다. [확정]

## 4. 경제 균형 요소 [요소만 확정, 수치 미정]

- 입력(비용): 재료 구매비
- 출력(수익): 판매가 = 레시피에 명시된 재료 양의 구매가 합산 × 품질 배율 (최하품 0.7 / 하품 1 / 중품 1.2 / 상품 1.5 / 최상품 2) [확정]
- 재료 가격은 Common을 1배로 Uncommon 1.2 / Rare 1.5 / Unique 1.8 / Legendary 2배, 소수점은 반올림 [확정]
- 시간: 1회 제작 소요 시간
- 아래는 모두 **[미정]**
  - Common 재료의 기준 가격 수치
  - 1회 제작 목표 시간
  - 시장 가격 변동 여부

## 5. 루프 밖 후속 기능 [확정: 추가 예정]

- 장비 강화: 판매가에 강화 수치가 반영됨 (기존 가격 공식과의 결합 방식은 미정)
- 숙련도 시스템
