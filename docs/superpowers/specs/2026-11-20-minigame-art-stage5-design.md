# 미니게임 이미지 교체 5단계 (힛 이펙트 텍스처) 설계

앞 단계: stage1~4 문서(같은 폴더). 힛 이펙트 원 설계: `2026-11-17-hit-effects-design.md`(불변식 포함). 작은 변경이므로 짧은 설계이며 "5단계 진행해줘"로 진행을 승인받았다.

## 범위

- 이펙트 이미지는 텍스처 2장이다. **같은 경로에 덮어써서 교체**한다(`.meta`·GUID 유지 → `HitRing.mat`/`HitEffect.mat`과 프리팹 참조 불변).
  - `Assets/Effects/Textures/SoftRing.png` (현재 128×128, `HitRing.mat`): 단조 판정 링. `ForgeHitPerfect/Good/Miss`의 링 파티클(시작 크기 320 = 기준 원 지름 160의 2배).
  - `Assets/Effects/Textures/SoftGlow.png` (현재 64×64, `HitEffect.mat`): 단조 불꽃(크기 0~11px), 연마 큰 번쩍임(0~180px)과 작은 반짝이(~12px). 틴트: 단조 금색(1,0.82,0.35), 연마 은색(0.85,0.88,0.95).
- 제외: 프리팹 구조·파티클 수치·정렬 레이어·크기 규칙·재질 셰이더, 힛 이펙트 코드, 화로 불꽃(`ForgeFlame`).
- 스타일: 이펙트는 additive(빛)이므로 갈색 외곽선 없이 흰색 빛 이미지로 만든다. 스타일 레퍼런스(`heat_bar_frame`)는 붙이지 않는다.

## 제약 (불변식)

- **링: 반지름 절반(0.5R) 안쪽은 알파 0.** 링 시작 크기가 기준 원 지름의 2배이므로 구멍이 곧 판정 원이다. 링 띠는 0.5R~R 사이에 있어야 하고 바깥 가장자리는 이미지 가장자리에 닿되 넘지 않는다. 생성 결과가 이를 지키지 않으면 후처리로 0.5R 안쪽 알파를 0으로 만든다(부드러운 경계).
- 두 텍스처 모두 **흰색/무채색**(틴트가 색을 정함), 외곽선 없음, 투명 배경, 정사각, 원/별의 중심이 이미지 중심.
- 파티클 텍스처는 작아야 한다: 링 512×512, 불꽃·반짝임 256×256으로 축소해 저장.
- 이펙트가 판정 원을 가리지 않고 클릭을 막지 않는 불변식은 그대로(파티클은 레이캐스트 대상 아님).
- 씬 파일은 이번 단계에서 바뀌지 않는다(에셋 덮어쓰기). 프리팹 참조는 텍스처 GUID로 유지된다.

## 작업 순서

1. 프롬프트 작성 → 2개 job 배치 생성 → `~/.codex/generated_images/`에서 복사.
2. 링: 0.5R 안쪽 알파 검사(필요하면 후처리), 512로 축소. 불꽃: 256으로 축소.
3. `SoftRing.png`/`SoftGlow.png` 덮어쓰기, 임포트 확인(타입 Default, alphaIsTransparency, mip 없음 유지).
4. 확인: 편집 모드에서 프리팹을 UI에 인스턴스해 `ParticleSystem.Simulate`로 여러 시점을 렌더링 — 단조 링이 원을 가리지 않는지, 판정별 3종, 연마 반짝임. 콘솔·참조 확인.

## 판단 (확인 필요)

- 불꽃·번쩍임은 4갈래 별 모양 반짝임(sparkle)으로 한다.
- 링은 빛무리 띠(shockwave ring)로 한다.

## 결과 (2026-11-20)

- 생성: `fx_ring`, `fx_sparkle` (각 1254×1254 원본, `generated-images/raw/`). 생성 결과의 배경 제거 노이즈(점 찌꺼기, 별 몸통의 거친 가장자리) 때문에 **대칭 평균 후처리**를 했다: 링은 반지름별 알파 평균으로 깨끗한 링을 재합성(512×512, **0.55R 안쪽 알파 정확히 0**으로 확정, 바깥 0.965R부터 가장자리 페이드), 별은 8방향 대칭 평균 후 256×256으로 축소. 처리 결과가 `generated-images/fx_ring.png`·`fx_sparkle.png`.
- 교체: `Assets/Effects/Textures/SoftRing.png`(512×512), `SoftGlow.png`(256×256)를 같은 경로에 덮어씀. `.meta`·GUID 불변, 임포트 설정(Default, alphaIsTransparency, mip 없음, sRGB, Clamp) 유지. 프리팹·재질·씬 변경 없음.
- 검증: 콘솔 오류 0(additive light 경고만), Game 씬 Missing Script 0, 복제본 잔여 0. 편집 모드에서 프리팹을 UI에 인스턴스하고 `ParticleSystem.Simulate`로 렌더링: 단조 Perfect/Good/Miss 3종을 0.06/0.14/0.24초에서 확인 — 링은 모든 시점에서 판정 원 바깥으로만 퍼지고 원을 가리지 않으며, Perfect > Good > Miss 순으로 크고 밝다. 연마 반짝임(은색 별 + 작은 반짝이)이 흠집 위에서 정상 렌더링. 플레이 모드 실제 재생·타이밍은 확인하지 않았다.
- 알려진 점: 링 띠가 이전 `SoftRing`보다 두껍고 불투명해 링이 더 굵게 보인다. 굵기가 과하면 링 텍스처의 띠 구간(0.62R~0.965R)이나 프리팹 `startColor` 알파를 조정한다.
