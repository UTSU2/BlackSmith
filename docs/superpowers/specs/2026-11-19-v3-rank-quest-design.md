# v3 설계 — 승급 퀘스트 (출하 3단계)

> **상태: 초안, 승인 대기** (2026-11-19). 상위 설계: [2026-11-19-v3-rank-skip-design.md](2026-11-19-v3-rank-skip-design.md). 아래 **[미정]**은 사용자가 정하며 임의로 정하지 않는다.

## 의도

승급을 퀘스트로 거치게 해서, 등급이 올랐다는 사실을 플레이어가 분명히 인지하게 하고 적당한 난이도로 성취감을 준다. 퀘스트를 클리어하는 즉시 팝업으로 승급과 혜택을 알려 성장 욕구를 키운다.

## 목표 / 비목표 / 안티목표

- **목표:** 승급 4번(초급, 숙련, 장인, 명장)마다 퀘스트 하나. 퀘스트는 **품질 도전**: 지정 레시피를 지정 품질 이상으로 제작. 클리어 즉시 승급 팝업.
- **비목표:** 일반 퀘스트 시스템, 퀘스트 수락 화면, 납품·수집·돈 목표 같은 다른 퀘스트 종류, 퀘스트 목록 화면.
- **안티목표:** 같은 일을 여러 번 반복시키는 퀘스트(v3 목적이 반복 피로 완화). 승급이 조용히 일어나 플레이어가 모르는 것. 세이브 호환이 깨지는 것.

## 접근 방식

- **A. 자동 시작 + HUD 표시 (선택).** 승급 조건(도감·master 개수)을 채우면 퀘스트가 자동으로 시작되고, HUD에 한 줄로 보이며, 조건에 맞는 제작을 끝내면 승급한다. 추가 화면은 승급 팝업 하나다.
- B. 수락 방식: 조건을 채우면 "퀘스트 받기"가 열린다. 패널·버튼·세이브 상태가 늘고, 목적(승급 인지)에 수락 단계는 큰 도움이 되지 않아 제외.

## 확정된 규칙

- 퀘스트 시작 조건 = 그 등급의 승급 조건(도감 해금 수 + master 수, 둘 다)을 채움. 별도 세이브 상태는 없다(조건과 등급으로 계산).
- 클리어 조건 = 제작이 끝났을 때 **결과 레시피가 퀘스트의 레시피**이고 **최종 품질이 퀘스트의 최소 품질 이상**(품질 보너스 적용 후 결과 품질). 알 수 없는 제작품(레시피 없음)은 해당 없음. 튜토리얼 중에는 퀘스트가 없다.
- 클리어하면 등급이 **한 단계만** 오른다. 다음 등급의 조건이 이미 충족돼 있으면 다음 퀘스트가 바로 시작된다.
- 재료는 일반 제작과 똑같이 소모된다. 실패해도 다시 도전할 수 있고 벌칙은 없다.
- 클리어 즉시 승급 팝업: `대장장이 등급: 초급 → 숙련`과 혜택 문구. 제작 결과 팝업이 떠 있으면 그 팝업을 닫은 뒤에 띄운다.
- 승급 퀘스트에는 개발용 임시 승급(`RankController.allowDirectPromotion`)을 **제거**한다.
- 퀘스트 내용(레시피, 최소 품질, 설명 문구)과 혜택 문구는 **[미정]**: 사용자가 에셋에 채운다. 에셋이 비어 있는 등급은 승급이 일어나지 않는다.

## 정해 둔 것 (제 선택, 사용자 확인 필요)

- 퀘스트 데이터는 `RankQuestSettings` ScriptableObject(`Resources/Rank/`) 하나에 등급별 항목(대상 등급, 설명, 레시피 id, 최소 품질)을 둔다. 규칙은 순수 C#(`RankQuestRules`).
- HUD 등급 표시 아래에 조건 미달이면 지금 진행도 줄을, 조건을 채웠으면 `승급 퀘스트: <설명>`을 보인다. 조건을 채웠는데 퀘스트가 비어 있으면 `승급 퀘스트 준비 중`이라고 보인다.
- 혜택 문구는 `BlacksmithRankSettings`의 등급별 항목에 둔다(숙련·명장은 스킵 장비 문구를 사용자가 쓴다). 문구가 비어 있으면 혜택 줄은 팝업에서 숨긴다(초급·장인은 혜택 미정).
- 승급 팝업은 자체 캔버스 순서 22(결과 팝업 20, 튜토리얼 21 위). 확인 버튼으로 닫는다.
- 스킵 장비를 켠 채로는 최상품(40)이 나올 수 없다. 최상품을 요구하는 퀘스트는 사용자가 설명 문구에 쓰거나 장비를 꺼야 한다는 점을 안내한다(자동으로 끄지 않는다).
- 퀘스트가 가리키는 레시피를 플레이어가 아직 발견하지 못했을 수 있다(레시피는 실험으로만 해금). 어떤 레시피를 고르고 문구로 어떻게 단서를 줄지는 사용자의 몫이다.

## 미정 (사용자가 정함)

등급별 퀘스트의 레시피·최소 품질·설명 문구, 혜택 문구, 승급 팝업의 비주얼(스프라이트·색), "승급 퀘스트 준비 중" 문구.

## 빌더에게 맡기는 부분

`RankQuestSettings`의 필드 구성, 클래스 분리, 팝업 구체 배치, HUD 한 줄 배치. Unity 검증은 CLAUDE.md 절차를 따른다.
