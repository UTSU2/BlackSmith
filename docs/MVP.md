# MVP — 최소 개발 범위

> **상태: 확정.** MVP 완성을 **v1**으로 본다. MVP에서 제외한 항목은 **v2**에서 추가해 완성한다. 각 항목의 세부 수치(종류, 가격, 등급 등)는 해당 문서의 미정 항목을 따르며 임의로 결정하지 않는다.

## 1. 목표 [확정]

- 핵심 루프(구매 → 제작 → 품질 → 판매)가 한 번 끝까지 돌아가는 최소 형태를 만들어, 제작 미니게임이 재미있는지 먼저 검증한다.

## 2. 포함 범위 [확정]

| 항목 | 범위 | 세부 사항 |
|---|---|---|
| 재료 | 소수(약 3종) | 종류 미정, Common 가격은 아이템 생성 시 아이템별로 결정 |
| 장비 | 소수(약 3종) | 종류 미정, 판매가는 레시피 재료 합산 × 품질 배율 |
| 미니게임 | 먼저 **단조**(리듬게임 형식, 핵심 재미) 1개를 만들어 검증한 뒤 나머지 3개 추가 | 추가 순서 미정. 난이도는 1~10단계, 판정과 단계별 수치는 확정 |
| 상점 | 광물 구매, 장비 판매 | UI, 수량 미정 |
| 품질/판매가 | 미니게임 점수 → 품질, 레시피 재료 구매가 합 × 품질 배율 → 판매가 | 규칙 확정 (Common 가격은 아이템별로 생성 시 결정) |
| 재화/인벤토리 | 돈과 보유 아이템 | 구조 미정 |
| 저장/불러오기 | 포함 | 세부 미정 |

## 3. MVP 제외 (v2에서 추가·완성) [확정]

- 장비 강화
- 숙련도 시스템
- 레시피 해금
- 적중 이펙트 (적중 사운드는 MVP에 포함)
- 정밀 밸런스 조정 (MVP에서는 아주 기본적인 조정만 한다. v2에서 세밀하게 조정해 완성한다)

## 4. 구현 완료 항목 (현재)

- 타이틀 씬(새 게임/로드 게임/설정/닫기), Game 씬 배경
- 아이템 데이터 레이어: `ItemData`, `MineralItemData`, `CraftedItemData`, `ItemDatabase`, 아이템 생성 툴
- 상점: 광물 구매, 완성품 판매 (구매/판매 탭, 팝업)
- 제작: 모루 클릭으로 시작, 가열·단조·열처리·연마 4개 미니게임, 레시피 매칭, 점수 → 품질, 완성품 지급, 레시피 생성 툴
- 돈·소지품과 저장/불러오기: 슬롯 8개. 타이틀의 로드 패널, Game 씬의 책 버튼 저장/불러오기 패널
- 현재 콘텐츠 에셋: 광물 48종(값 확정), 실제 이름의 완성품 11종과 레시피 11개(철검 포함), 임시 완성품 5종(`temp_gear_*`)과 임시 레시피 38개. 임시 레시피는 아직 실제 장비에 쓰이지 않은 광물을 위한 것이며 장비를 추가하면서 교체한다.
- 미니게임 판정 규칙과 난이도별 수치는 확정됐고 코드에 반영했다. 실제 난이도 체감은 플레이로 검증해야 한다
- 1회 제작 시간은 가열 5 / 단조 8 / 열처리 2 / 연마 5초(합계 20초)로 코드와 `Game` 씬에 반영했다. (연마는 흠집을 모두 지우면 일찍 끝날 수 있다)
- 사운드: 미니게임 효과음 9종(가열 1, 단조 3, 열처리 3, 연마 2, `Assets/Audio/Sfx`)과 BGM 2곡(기본 / 제작 중, `Assets/Audio/Bgm`). 제작 시작부터 완료까지만 제작 BGM을 쓰고, Title·Game은 씬마다 처음부터 재생한다. 파일은 임시다. 계획과 결정은 [SoundPlan.md](SoundPlan.md)
- 설정: Title(로드 게임과 닫기 사이 설정 버튼)과 Game(우상단 톱니바퀴 버튼)에서 BGM / 효과음 소리 크기를 슬라이더로 조절한다. 값은 `PlayerPrefs`에 저장한다. Game 설정 패널에는 타이틀로 돌아가기가 있고, 저장 이후 금액·소지품 변경이 있을 때만 확인 창이 뜬다
- 새 게임: 튜토리얼이 아직 없어 건너뛴 것으로 처리하고 소지금 1000원으로 시작한다. (튜토리얼이 생기면 완료·스킵 시 지급)

## 5. 완료 기준 (= v1) [확정]

아래를 모두 갖추면 MVP(v1)를 완료한 것으로 본다.

- 광물과 제작품을 임시로라도 완성한다. (이름·가격·난이도가 임시값이어도 된다. 모든 광물에 이를 쓰는 레시피가 있어야 한다.)
- 미니게임 적중 사운드를 추가한다.
- BGM을 추가한다.
- 아주 기본적인 수준의 밸런스 조정을 한다. (정밀 조정은 v2)
- 1회 제작 목표 시간은 20초로 확정됐다. ([GameDesign.md](GameDesign.md) §4)

### 현재 충족 현황

| 기준 | 상태 |
|---|---|
| 광물·제작품 임시 완성, 모든 광물에 레시피 | 충족 (광물 48종, 완성품 16종, 레시피 49개) |
| 미니게임 적중 사운드 | 충족 (효과음 9종, 파일은 임시) |

| 아주 기본적인 밸런스 조정 | 진행 중. 제작 시간은 조정했고, 열처리 난이도 10, 재료 가격·판매가 체감 점검이 남음. 충족 판단은 개발자가 한다 |
| 1회 제작 목표 시간 20초 | 반영 (가열 5 / 단조 8 / 열처리 2 / 연마 5) |
