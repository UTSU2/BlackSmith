# MVP — 최소 개발 범위

> **상태: 확정.** 단, **완료 기준은 미정**이다. 각 항목의 세부 수치(종류, 가격, 등급 등)는 해당 문서의 미정 항목을 따르며 임의로 결정하지 않는다.

## 1. 목표 [확정]

- 핵심 루프(구매 → 제작 → 등급 → 판매)가 한 번 끝까지 돌아가는 최소 형태를 만들어, 제작 미니게임이 재미있는지 먼저 검증한다.

## 2. 포함 범위 [확정]

| 항목 | 범위 | 세부 사항 |
|---|---|---|
| 재료 | 소수(약 3종) | 종류, 가격 미정 |
| 장비 | 소수(약 3종) | 종류, 기본 판매가 미정 |
| 미니게임 | 먼저 **단조**(리듬게임 형식, 핵심 재미) 1개를 만들어 검증한 뒤 나머지 3개 추가 | 추가 순서, 난이도 미정 |
| 상점 | 광물 구매, 장비 판매 | UI, 수량 미정 |
| 등급 | 완성도 → 등급 → 판매가 | 등급 이름/개수/배율, 산식 미정 |
| 재화/인벤토리 | 돈과 보유 아이템 | 구조 미정 |
| 저장/불러오기 | 포함 | 세부 미정 |

## 3. MVP 제외 [확정]

- 장비 강화
- 숙련도 시스템
- 레시피 해금

## 4. 구현 완료 항목 (현재)

- 타이틀 씬(새 게임/로드 게임 버튼/닫기), Game 씬 배경, 상점 아이콘 버튼
- 아이템 데이터 레이어: `ItemData`, `MineralItemData`, `CraftedItemData`, `ItemDatabase`, 아이템 생성 툴

## 5. 완료 기준 [미정]

- "재미있다"를 판단하는 기준, 1회 제작 목표 시간, 플레이 가능한 최소 콘텐츠 양: **[미정]**
