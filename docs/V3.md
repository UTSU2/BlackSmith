## 2. 대장장이 등급 [확정]

- 견습 → 초급 → 숙련 → 장인 → 명장. 시작은 견습이며 견습의 조건은 튜토리얼 클리어다(튜토리얼 중에는 등급 표시가 없다). 옛 세이브는 견습이다.
- 승급 조건: **도감 해금 수**와 **master 숙련도 수**를 각각 따로 세고 둘 다 채워야 한다. 필요 개수는 사용자가 입력했다(§5, `Resources/Rank/BlacksmithRankSettings.asset`). 값이 -1이면 여전히 미정 = 승급 불가다.
- 승급 흐름: 조건(도감 수 + master 수) 충족 → 퀘스트 자동 시작(HUD 한 줄, 수락 화면 없음) → 클리어 → 한 단계 승급 + 승급 팝업.
- 퀘스트는 **품질 도전**이다: 지정 레시피를 지정 품질 이상(품질 보너스 적용 후)으로 제작. 알 수 없는 제작품과 튜토리얼 제작은 해당 없다. 재료는 평소처럼 소모되고 실패해도 다시 도전할 수 있다. 세이브에 퀘스트 상태는 없고 등급과 개수로 계산한다.
- 내용(등급별 레시피 id·최소 품질·설명)은 `Resources/Rank/RankQuestSettings.asset`, 혜택 문구는 `BlacksmithRankSettings`의 등급별 `benefitText`에 사용자가 입력했다(§5). 값을 바꿀 때도 사용자가 정한다. 항목이 비어 있으면 그 등급은 승급하지 않고 HUD에 `승급 퀘스트 준비 중`(임시 문구)이 보인다. 스킵 장비를 켠 채로는 최상품이 나오지 않으니 최상품 퀘스트(명장)는 장비를 꺼야 한다(자동으로 끄지 않음). 품질 보너스를 더해도 총점 상한이 39라 최상품은 보너스 없이 직접 40점을 받아야 한다([V2.md](V2.md) §2).
- HUD 둘째 줄: 조건 미달이면 진행도, 진행 중이면 `승급 퀘스트: <설명>`(설명이 비면 레시피 id와 품질로 임시 표기), 최고 등급이면 `최고 등급`.
- 승급 팝업(`RankPromotionPopup`, 캔버스 순서 22): `대장장이 등급: 초급 → 숙련` + 혜택 문구(비면 숨김), 확인 버튼. 결과 팝업이 떠 있으면 닫힌 뒤에 보인다. 비주얼은 임시이며 **[미정]**.
- 구현 추가: `RankQuestSettings`, `RankQuestRules`(`RankQuestState`), `RankController.Promoted/HandleCraftResult/GetQuestState`.
- 혜택: 숙련 = 가열 스킵 장비, 명장 = 열처리 스킵 장비(가열 스킵도 계속 사용). **초급부터 판매 가격 ×1.1, 장인부터 ×1.3**(2026-11-20, 사용자 결정; 배율은 누적하지 않고 장인 이상은 ×1.3만 적용, 견습은 ×1). 상점 판매 단가(광물·제작품 모두)에 곱하며 반올림은 가격 규칙(0.5는 올림)이다. 배율은 `BlacksmithRankSettings`의 등급별 `sellPriceMultiplier`에 있다. 승급 팝업의 혜택 문구에는 아직 이 내용이 없다(문구는 사용자가 입력).
- HUD 왼쪽 위에 `대장장이 등급: 숙련` 아래 한 줄로 `도감 a/N · master b/M`(필요 개수 미정이면 `-`).
- 구현: `Assets/Scripts/Rank`(`BlacksmithRank`, `BlacksmithRankSettings`, `BlacksmithRankRules`, `RankCounter`, `RankController`), `PlayerData.rank`, `RankHud`(`UI`).
- 이름 "초급"은 숙련도 단계 이름(초급·중급·고급)과 겹친다. 이름을 바꿀지 **[미정]**(지금은 HUD에 "대장장이 등급" 라벨로 구분).

## 3. 스킵 장비 [확정]

- 가열용과 열처리용 두 가지. 켜기/끄기, Lv1~5.
- 켠 상태로 제작하면 그 단계의 미니게임을 하지 않고 **고정 점수**가 들어간다: Lv1 5 / Lv2 6 / Lv3 7 / Lv4 8 / Lv5 9. 최대 9점이므로 스킵을 쓰면 최상품(40)이 나오지 않는다(가열만 39, 둘 다 38).
- 스킵한 제작도 총점에 따라 숙련도를 쌓는다([V2.md](V2.md) §2 규칙 그대로). 튜토리얼 제작에는 스킵이 없다.
- 장비는 등급이 해금 등급 이상이면 지급되고(`RankController`가 시작·승급 때 동기화, 이미 가진 장비는 건드리지 않음) 지급 직후 Lv1·켜짐이다.
- 켜기/끄기와 강화는 제작 패널의 스킵 줄(`SkipGearRow`)에서 한다. 강화 비용은 사용자가 입력했다(§5, `SkipGearSettings`). 값이 -1이면 강화 불가다. 장비 이름·아이콘·UI 비주얼도 **[미정]**.
- 결과 팝업의 품질 보너스 줄에 `스킵 가열·열처리`가 덧붙고, 제작 로그에는 `스킵(n점)`이 보인다.
- 구현: `SkipGearKind/Entry/Settings/Rules/Service`, `PlayerData.skipGears`, `CraftStageResult(stage, fixedScore)`(기존 `Skipped`는 "미구현 단계, 0점"으로 다른 뜻), `CraftScoring.CalculateScore`, `CraftingController`(`TryGetSkipScore`).
- 세이브: 필드가 없는 옛 세이브는 견습·장비 없음으로 읽힌다. `SaveFile.CurrentVersion`은 1 그대로.

## 4. 미정 목록 (2026-11-20 기준)

- (해결됨) 초급·장인 혜택 = 판매 가격 배율 ×1.1 / ×1.3 (§2)
- 승급 팝업 비주얼 (임시)
- 스킵 장비 이름·아이콘·UI 비주얼
- 등급 이름 "초급"과 숙련도 단계 이름(초급·중급·고급)의 겹침
- 장비 38종의 이름·재료 조합 최종 확정 (초안 상태, 재료를 바꾸면 난이도를 다시 계산)

## 5. 입력된 값 (사용자 입력, 2026-11-19, 커밋 `6031194`)

**승급 필요 개수** (`BlacksmithRankSettings`)

| 승급 | 도감 해금 수 | master 수 |
|---|---|---|
| 견습 → 초급 | 10 | 5 |
| 초급 → 숙련 | 25 | 15 |
| 숙련 → 장인 | 49 | 30 |
| 장인 → 명장 | 49 | 49 |

**승급 퀘스트** (`RankQuestSettings`, 품질은 보너스 적용 후 최소 품질)

| 승급 | 레시피 | 최소 품질 |
|---|---|---|
| 초급 | 옥 장검 (`recipe_jade_longsword`) | 중품 |
| 숙련 | 청옥 사브르 (`recipe_azure_saber`) | 중품 |
| 장인 | 흑요 할버드 (`recipe_obsidian_halberd`) | 상품 |
| 명장 | 용심 루비 대검 (`recipe_dragonheart_greatsword`) | 최상품 |

**스킵 장비** (`SkipGearSettings`)

- 해금 등급: 가열 스킵 = 숙련, 열처리 스킵 = 명장
- 강화 비용(골드): Lv1→2 20000, Lv2→3 40000, Lv3→4 70000, Lv4→5 120000
- 스킵 점수: Lv1~5 = 5 / 6 / 7 / 8 / 9

혜택 문구는 승급 팝업에 보이는 등급별 축하 문구이며 에셋(`benefitText`)에 들어 있다.

## 6. 확인 기록이 없는 것

플레이 모드 검증은 임시 설정값으로 했고(구현 계획의 검증 단계, 에셋 원복), **위 입력값으로 처음부터 끝까지 플레이해서 확인한 기록은 없다.** 확인되면 이 목록에서 지운다.

- 승급 흐름 전체: 조건 충족 → 퀘스트 자동 시작 → 클리어 → 승급 팝업
- 명장 퀘스트(최상품): 스킵 장비를 끄고 보너스 없이 직접 40점을 받아야 하는 난이도
- 도감 49개·master 49개 요구량과 스킵 장비 강화 비용(20000~120000)의 균형
