# Tutorial — 튜토리얼 설계

> **상태: 확정.** v2 범위. 아래 **[미정]** 항목은 임의로 정하지 않는다.

## 1. 목적

- 새 게임 플레이어가 첫 장비를 직접 만들어 팔아 보면서 **재료 투입과 매칭 규칙**을 익힌다.
- 레시피 북이 없고 투입한 재료가 제작 시작 시 모두 소모되므로, 가르치지 않으면 재료를 낭비하기 쉽다.

## 2. 목표 / 비목표

- 목표: 구매 → 제작 → 판매 한 바퀴를 끝까지 체험시키고, 설명 팝업으로 규칙을 알려 준다.
- 비목표: 4개 미니게임 조작법 상세 교육, 등급·품질·가격 공식 설명, 레시피 해금. (미니게임 조작 안내 팝업을 넣을지는 **[미정]**)
- 안티 목표: 재료 낭비로 흐름이 끊기는 것, 튜토리얼 로직이 상점·저장 UI 곳곳에 흩어지는 것.

## 3. 흐름 (확정된 결정)

1. 새 게임 시작 시 **재료 구매용 금액만** 지급한다. 금액 = 튜토리얼 정답 재료의 구매가 합(값을 새로 정하지 않고 계산으로 구한다).
2. 상점에서는 **튜토리얼 재료만 구매 가능**하다. 나머지 광물은 잠긴다.
3. 첫 제작: 팝업이 **정답 재료와 수량을 그대로 알려 준다.**
4. 제작 완료 후: 팝업이 **매칭 규칙을 설명**한다. (수량만 본다 / 가장 가까운 레시피로 만들어진다 / 투입한 재료는 모두 소모된다)
5. 완성품을 상점에서 판매하면 튜토리얼이 끝나고 **1000원을 지급**한다. (`CompleteTutorial()`)
6. **스킵은 없다.** 새 게임에서는 반드시 거친다.
7. 튜토리얼 중에는 **저장을 막는다.** 도중에 타이틀로 나가면 진행은 사라지고 새 게임은 처음부터 다시 시작한다. 단계 진행도는 세이브에 저장하지 않는다.
8. 옛 세이브(`tutorialPending` 필드 없음)는 지금처럼 완료로 처리하며 보상이 없다.

## 4. 접근 방식

| 안 | 내용 | 평가 |
|---|---|---|
| **A. 단계 데이터 + 컨트롤러 (채택)** | 단계를 ScriptableObject로 두고 `TutorialController`가 기존 이벤트로 진행. 상점·저장 UI는 "튜토리얼 중인가 / 이 품목이 허용되는가"만 질의 | 문구·순서를 데이터로 수정, 제한을 한곳에서 관리. 초기 구조 비용 |
| B. 코루틴 하드코딩 | 한 스크립트에 순서를 직접 작성 | 빠르지만 문구 수정이 코드 수정, 분기가 흩어짐 |
| C. 전용 씬 | 제한된 상점·제작 UI를 복제 | UI가 두 벌이 되어 유지 부담 |

## 5. 구조 (A안)

- `TutorialStepData` (ScriptableObject): 팝업 문구, 완료 조건 종류, 허용 구매 품목. 단계 순서는 목록(에셋)으로 둔다.
- `TutorialController` (`BlackSmith.Tutorial` 등 새 폴더/네임스페이스는 폴더와 맞춘다): 현재 단계 보유, 이벤트를 듣고 다음 단계로 이동. 구독은 `OnDisable`에서 해제한다.
- 이벤트 소스: 제작은 `CraftingController.CraftStarted/CraftFinished`가 이미 있다. **상점 구매/판매 완료 이벤트는 확인 후 없으면 추가**한다.
- 게이트 질의: 상점은 품목별 구매 허용 여부, 저장 패널은 저장 가능 여부, 설정 패널은 타이틀 복귀 확인창 표시 여부를 컨트롤러에 묻는다.
- 팝업 UI는 `BlackSmith.UI`에 두고, 글자가 있는 버튼은 `ButtonLabelPress`를 붙인다.
- `GameSession.StartNew`: 시작 지급을 추가하고 `CompleteTutorial()`은 튜토리얼 마지막 단계로 옮긴다. `StartTutorial()`은 유지한다.

## 6. 미정 / 빌더 몫

- 튜토리얼에 쓸 **장비와 레시피, 정답 재료와 수량** — **[미정]** (사용자가 정한다)
- 팝업 문구 전부 — **[미정]**
- 미니게임 조작 안내 팝업 여부 — **[미정]**
- 팝업 디자인(위치, 화면을 가리는지, 해당 UI 강조 여부) — **[미정]**
- 시작 지급 금액은 정답 재료 구매가 합으로 계산한다. 등급별 가격 배율(`ItemGradeInfo`)과 반올림 규칙을 그대로 따른다.
- 제작 도중 비정상 종료·씬 전환 시 컨트롤러 상태 정리 방식은 구현 시 정한다.

## 7. 검증

- 튜토리얼 중: 허용되지 않은 광물은 구매할 수 없고, 저장 버튼이 잠기며, 타이틀 복귀 시 확인창이 뜬다.
- 완료 후: 1000원 지급, 저장·구매 제한 해제, 이후 세이브에 `tutorialPending`이 완료로 기록된다.
- 옛 세이브 로드 시 튜토리얼이 뜨지 않는다.
